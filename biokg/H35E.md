# H35E: private dot-product versus L1-distance internal branch

Preregistered 2026-09-06 before real-data H35E training/scoring. User approved
three fixed arms after the negative H35D rank-fusion diagnostic. This is an
adaptive, single-seed, 5,000-update warm-start screen, not a leaderboard run.
Only the local GTX 1080 Ti; do not use the rented machine.

## Fixed arms and exact scoring

All start A from the original released BioKG `dist_T2_s0.pt`, not an adapted
checkpoint. A retains its 144 complex entity features, 36 complex 4x4 blocks
per directed relation, normalization, raw target readout and temperature.

1. `single`: A alone; all original parameters trainable.
2. `dot`: A plus a private 32-real-dimensional entity table B and dot scoring.
3. `distance`: identical parameterization to `dot`, replacing only its B
   scoring geometry with negative unsquared L1 distance.

B is initialized independently of A, CPU RNG seed 35130, normalized random
normal entity rows. Dot and distance receive exactly identical initial
parameter values in separate storage. Both have head scales, tail scales,
translation, directed-relation gate and a private scalar temperature:

```
u = normalize(B[source]) * head_scale[r] + shift[r]
v = normalize(B[candidate]) * tail_scale[r]
b_dot = sqrt(32) * sum(u * v)
b_distance = -sum(abs(u - v))
s = s_A + sigmoid(gate_logit[r]) * exp(log_tau_b) * b
```

All products in the private maps are elementwise. Scales start at one, shift
at zero, private log-temperature at zero, gate at 0.05 (nonzero so B receives
gradients immediately). There are 102 directed relations, independently
parameterized as in A. The gate depends on relation/direction, never candidate
position, candidate-set composition, VALID statistics or correctness labels.
Raw dot is multiplied by sqrt(width) to give approximately unit scale at
random normalized initialization; L1 is not squared and receives no fitted
calibration. Its negative query-wide offset does not affect CE/KD rankings.
Dot/distance do not have identical initial predictions; that is part of the
fixed scorer intervention, not evidence of specialization.

Real parameter counts: single 27,124,129; dot and distance each 30,134,760.
Private branch adds 3,010,631 parameters (~11.1%), not merely a second tiny
operator bank. Dot is the equal-parameter control; comparison cannot separate
geometry from all its effects on optimization. One jointly trained checkpoint
at inference, without teachers or validation-dependent score tables.

## Matched training and retained loss

- Exactly 5,000 updates per arm; same TRAIN stream as H35C (private seed 3510),
  relation-frequency sampling, uniform direction, batch 2,048 and 4,096 shared
  typed random negatives. Evaluate the same ten frozen released teachers once
  per batch and reuse their mean raw logits across the independent arms.
- Retain original loss in every arm:
  `CE(s, positive) + 4*KL(softmax(mean_teacher_logits/2) || softmax(s/2))`
  `+ 0.1*mean(||q_A - raw_E_positive||^2)`.
  No B alignment penalty, auxiliary labels, ranking targets, negative mining,
  validation training, diversity loss, graph features or teacher updates.
- Fresh dense Adam, no weight decay, default betas/epsilon. A LR 0.0001 in
  all arms; newly initialized B/maps/gate/temperature LR 0.001 in both added-B
  arms. Both groups cosine-decay to zero over 5,000 updates; global gradient
  clip 1.0 per arm. All embeddings, maps, gates and temperatures co-adapt.
  This is not a resume of the original sparse optimizer. B's higher LR is a
  fixed cold-start choice, not selected from validation.
- Complex64/fp32, no AMP/TF32. Native L1 pairwise distance for shared negatives;
  mathematically equivalent candidate-symmetric evaluation. Unit tests verify
  scorer/gradient parity with a direct implementation.
- Synthetic full-shape GPU smoke before real-data launch: finite gradients,
  all groups update, frozen teachers unchanged, time and peak memory. If it
  cannot fit, stop before real data; do not silently change the training batch.

## Evaluation, interpretation and stop

- TRAIN/VALID selective loader only; no TEST split, predictions or metrics.
  Verify dataset, student, teacher release, prior sources and reference hashes.
- Same fixed H35 progress probe: 1,000 VALID triples, both directions and all
  500 official negatives. Evaluate step 0 and every 500 updates. Probes are
  read-only and RNG-neutral; log LR, last-probe step/MRR and losses at least
  once per minute. No score-driven early stop, LR change or endpoint selection.
- Evaluate all three fixed endpoints on full VALID once (325,772 directed
  queries); official average-tie OGB ranks. Report each versus the original
  frozen student, and branch-alone ranks, gate distribution, score correlation,
  B correction spread, A/B top-1 disagreement, and recovered/lost A predictions.
  These diagnostics are not alternative selected inference models.
- Primary geometry comparison: distance minus dot. Promotion additionally
  requires distance minus equally trained single and distance minus frozen.
  Each delta must be >= +0.001 with a positive paired-triple bootstrap lower
  bound. Use 1,000 replicates and seed 3514, 98.3333% marginal intervals
  (Bonferroni for these three comparisons). Report dot-versus-single and all
  direction/family slices descriptively; do not promote dot via post-hoc tests.
- A positive screen needs other seeds and feature-pipeline checks. A negative
  screen rejects this finite recipe, not all private representations or L1
  architectures; 5,000 updates may be insufficient for a fresh branch.
- Preserve all three endpoints, per-query records, update/RNG/hash audits,
  standalone restore tests and sources. Stop after the fixed screen; do not
  automatically start a new width/gate/LR/objective sweep.
