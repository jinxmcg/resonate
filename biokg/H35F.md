# H35F: directly supervised B warm-up before joint training

Registered 2026-09-06, before real H35F data scoring/training. User explicitly
approved this three-arm two-stage experiment. Local GTX 1080 Ti only; no rented
GPU. Single-seed adaptive development screen, not a submission.

## Fixed architecture and arms

Reuse H35E's exact single and private dot-B inference models without editing
their source. A starts at released `dist_T2_s0.pt`; B uses the same independent
random initialization (seed 35130), 32 real features, head/tail scales and
translation. Private temperature initially 1, directed-relation gate 0.05.
Joint and warmup arms have identical initial tensors in independent storage.
No L1 arm, new feature, width, initialization, scoring or gate sweep.

| Arm | Updates 1–10,000 | Updates 10,001–15,000 |
| --- | --- | --- |
| single | Train A with original objective | Continue unchanged |
| joint | Train A+B with original combined objective | Continue unchanged |
| warmup | Freeze A and gate; directly supervise B | Unfreeze A/gate; use original combined objective |

B warm-up logits are `exp(log_tau_b)*sqrt(32)*dot(u,v)`, with the exact
H35E private head/tail maps. Neither A nor the gate is evaluated for this
training loss. The existing combined score is retained for read-only probes
and final deployment. Warm-up loss:

`CE(B_logits, TRAIN_positive) + 4*KL(softmax(mean_teacher_logits/2) || softmax(B_logits/2))`.

There is no warm-up A trajectory loss and no independent B loss after the
switch. The existing joint objective is then restored exactly:

`CE(combined_logits, TRAIN_positive) + 4*KL(teacher_T2 || combined_T2)`
`+ 0.1*mean(||q_A - raw_E_positive||^2)`.

## Training budget and schedules

- Exactly 15,000 optimizer updates per arm, same TRAIN stream seed 3510,
  batch 2,048, 4,096 shared typed random negatives, relation-frequency
  sampling and uniform prediction direction. Reuse each batch's same frozen
  ten-teacher mean raw logits across all arms. First 5,000-batch digest must
  match H35C/H35E; record 10,000- and 15,000-batch digests too.
- Fresh dense Adam with default betas/epsilon and no weight decay. One shared
  15,000-step cosine schedule: configured A LR 0.0001 and B LR 0.001, both
  decay to zero. No phase-boundary optimizer reset or LR restart. Warmup A
  and gate have no gradients or Adam state during the first 10,000 updates;
  effective LR is logged as zero while frozen. B moments carry across the
  switch. When A/gate unfreeze, configured rates are already partway through
  the common cosine schedule. Log configured and effective rates explicitly.
- Single A gets 15,000 parameter updates; joint A/B/gate each 15,000; warmup
  B gets 15,000 and A/gate get 5,000. Examples/optimizer calls are matched,
  not per-parameter updates or wall-clock time. This tests the two-stage
  training strategy including freezing/schedule exposure, not warm-up in
  isolation from every optimization effect.
- Global gradient clip 1.0 per arm on trainable parameters. Complex64/fp32,
  no AMP/TF32. No new auxiliary labels, error weighting, mining, graph inputs,
  validation supervision, score-selected continuation or adversarial objective.
- Real parameters unchanged: single 27,124,129; joint/warmup 30,134,760 each.
  Teacher parameters/compute disclosed; one self-contained model at inference.

## Verification, evaluation and decision

- Selectively load TRAIN and VALID only. Verify release teacher/student,
  dataset/reference and all H35E source hashes. No TEST files, candidates,
  predictions or metrics. Historical exposure and adaptive VALID reuse remain
  disclosed; this protocol does not certify or erase earlier history.
- Before real data: unit tests and full-size synthetic CUDA smoke for both
  phases. Verify ungated B logits/loss/gradients against direct formulas;
  A/gate unchanged with absent gradients/Adam state during warm-up; B updates;
  switch restores original joint objective and all groups update; teachers
  remain frozen; optimizer momentum is retained; candidate symmetry and
  teacher-free checkpoint restore. Abort before real training on OOM/nonfinite
  smoke rather than silently changing batch size or precision.
- Same H35 read-only 1,000-triple VALID probe at step 0 and every 500 updates;
  both directions and all supplied negatives. Report combined MRR and separate
  A/B-alone MRR, gate, private scale and last-probe step. These are descriptive,
  not best-checkpoint selection. Log effective LR/loss/progress at least once
  per minute; never represent frozen A's configured LR as an active update.
- At step 10,000, before unfreezing warmup A/gate: hash every group, confirm
  those frozen groups match initialization exactly and B groups changed; audit
  Adam step counters (A/gate zero, B 10,000); archive warmup boundary checkpoint.
  It is an audit artifact, not an alternative selected endpoint. No full VALID
  evaluation or hyperparameter decision at this boundary.
- Finish all arms at step 15,000, then evaluate full VALID once per endpoint:
  162,886 triples / 325,772 directed queries, 500 official negatives, OGB
  average-tie ranks, every candidate scored identically.
- Primary warmup-vs-joint MRR; promotion additionally requires warmup-vs-single
  and warmup-vs-original-frozen. Each delta >= +0.001 and each adjusted lower
  bound > 0. Paired whole-triple bootstrap 1,000 replicates, seed 3516,
  98.3333% marginal intervals (Bonferroni for these three comparisons).
- Descriptive checks: endpoint A/B-alone MRR, score correlation, gate and B
  correction/A score spread; original-missed/top-1-correct query cohorts,
  recoveries versus new breakages, and direction/relation-family results.
  These validation failures remain diagnostic only and never become training
  examples, sampling weights, auxiliary labels or targets.
- Preserve endpoints, boundary artifact, query records, all losses/schedules,
  update counts, stream/hash and standalone audits. Finish with no automatic
  new run. A positive screen needs seed confirmation and feature-pipeline
  checks. A negative screen does not rule out longer/from-scratch training or
  prove private B can never learn the missing information.
