# H35C — joint learning with the original distillation signal

Registered before H35C real-data execution. User explicitly approved joint
embedding/operator learning against an equally trained single-operator control.
This is a **5,000-update warm-start screen**, not a from-scratch reproduction,
an exact optimizer resume, or a multi-seed confirmation. Local GTX 1080 Ti.

## Models and role of the second bank

- Both start from released `dist_T2_s0.pt` (seed 0), SHA256
  `b463a8bcc431ada38f4834e235677464f9cd3a86346f88aecd2fd681a01260ef`.
- Control: one bank, all E/H/log_tau parameters trainable (27,124,129 reals).
- Treatment: two 4×4 banks, one shared E, one log_tau; **all parameters
  trainable** (27,241,633 reals). Bank A starts at the original operator;
  bank B starts at A plus 5% per-block Frobenius perturbation, private CPU
  RNG seed 35003, as in H35. No perturbation sweep.
- Fixed smooth-OR combination in scaled-logit units, T_combine=1:
  `s = logaddexp(s_A, s_B) - log(2)`. No mean/AND/permutation/gate sweep.
- A retains the original trajectory/alignment role. B can supply alternative
  scoring evidence through CE and KD without a separate trajectory penalty
  that pulls B toward every positive. Both operators and E co-adapt.
  This is a hypothesis about useful specialization, not assigned biological
  semantics or a guaranteed outcome. Do not impose arbitrary orthogonality.

## Exact retained loss

The frozen teachers are the released sparse-shell BioKG seeds 0–9, in their
equivalent dense checkpoint format. Their individual entity/operator/temperature
weights are frozen; all ten files must match the release SHA256SUMS. Teacher
and student indexing must match TRAIN/VALID exactly. Their recorded recipes
use no distillation; historical test exposure remains disclosed.

For each TRAIN batch, evaluate all ten teachers on **that same positive and
same 4096 shared typed negatives**. Average raw logits in seed order, then
softmax at temperature 2. This is not an average of teacher probabilities.

`L = CE(student_logits, positive_column)`
`    + 1.0 * 2^2 * KL(softmax(mean_teacher_logits/2) || softmax(student_logits/2))`
`    + 0.1 * mean(||q_A - E_positive||^2)`.

The control's sole query takes q_A's place. The trajectory uses the original
raw target embedding, not its normalized version. With identical treatment
branches, scores and all three loss values reduce to the control's values.
No new diversity/auxiliary loss, no removal of KD/trajectory, no known-positive
masking, no new features. This objective gives the two banks asymmetric
trajectory roles; it is not a pure score-only ablation.

## Matched training

- Two independent students, each initialized from the original student—not
  H35/H35B adapted weights. No parameters, gradients, optimizer state or student
  predictions shared between them. They are not combined at inference.
- Exactly **5,000 updates each**, same TRAIN stream seed 3510, relation-weighted
  sampling, uniform head/tail choice, batch 2048, 4096 typed random negatives.
- Compute the frozen teacher target once per batch and reuse it for both
  students. Update the two students sequentially within each batch on one GPU;
  this saves teacher forward passes without coupling the students.
- Dense Adam on **all** student parameters, LR **0.0001**, cosine to zero,
  global gradient clip 1.0. Original final checkpoints have no optimizer state;
  both students get fresh identical optimizer settings. The original sparse
  RowAdagrad/Adam training is **not** resumed or claimed to be reproduced.
- Complex64/fp32 throughout, no AMP/TF32. Ten teachers are training-only and
  their parameters/compute must be disclosed; the exported student checkpoint
  has no teacher dependency at inference.
- Before launch: synthetic full-shape CUDA smoke estimates memory/runtime;
  no real-data loss/probe used to choose budget, LR or combination.
- Verify nonzero finite gradients and actual parameter changes for E, A/B and
  log_tau. Hash teacher state before/after; require no teacher gradients.
  Record equal student update counts, shared TRAIN digest, component losses,
  LR, timing, peak memory, query cosine and branch responsibilities.

## Evaluation and stop

- TRAIN/VALID selective loading only. No TEST split, cache, labels or results.
  Validation labels are not used for gradients, teacher targets or graph input.
- Same 1,000-triple read-only progress probe as H35 (private seed 3501), both
  directions/all 500 official negatives, at initialization and every 500
  updates. No early stopping, LR changes, best-probe checkpoint selection,
  restarts with changed settings, or adaptive extensions.
- Reuse H35's frozen-student full-validation reference only after verifying
  checkpoint/data hashes and probe-index identity. Full validation once per
  trained student at update 5,000: all 325,772 directed queries, all official
  negatives, fp32 scoring, official average-tie ranks checked with OGB.
- Primary comparison: dual versus equally trained single. Also report both
  versus the frozen student. Two promotion comparisons: dual-minus-single and
  dual-minus-frozen. Paired-triple bootstrap 97.5% intervals (1,000 replicates,
  seed 3512), Bonferroni for these two only. Adaptive project-wide validation
  reuse and training-seed uncertainty are not removed by these intervals.
- Worth confirming only if both deltas >=0.001 and both interval lower bounds
  >0. A result that merely loses less than a degraded control is not promoted.
  Success still requires other seeds and the feature pipeline before submission.
- If negative, retain the original student, archive both endpoints and stop.
  Do not start a new frozen-bank combination or structural-teacher sweep.

## Required correctness checks

Single-model logits and CE/KD/trajectory parity with the original implementation;
teacher mean-logit aggregation and T² scaling; no teacher gradients/mutation;
all student parameter groups update; identical-head reduction; candidate
permutation; independent optimizers; read-only RNG-neutral probes; complete
checkpoint restore; TRAIN/VALID-only loader. Preserve all prior H35 sources.
